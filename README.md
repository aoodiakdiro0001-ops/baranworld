# 📝 Baran World — Document Editor + On-Device AI (MIT)

Word-class writing app by Baran Avisat. UI in EN/TR/AR. Static + README.

## Editor

Full toolbar (bold/italic/underline/strike, H1/H2, align, lists, indent,
fonts, sizes, colors, highlight, links, HR, tables, images, text direction,
find & replace), multi-document sidebar with auto-save (localStorage),
templates (letter/report/meeting), TXT/HTML export, print-to-PDF,
dark/light theme, fullscreen, live word count.

## On-Device AI (no server, no keys)

Extractive summarizer (frequency-ranked sentences), keyword extraction
(multilingual stopwords), Flesch readability, title suggestion, TOC from
headings. Honest limits stated in-app.
